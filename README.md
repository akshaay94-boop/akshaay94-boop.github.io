# Our Ethos · Live

The phone page for the IHC "Our Ethos" townhall live polls and quiz, served by GitHub Pages at https://akshaay94-boop.github.io/ethos/

It holds no questions, names or IHC content. Phones join with the six-character code shown on the wall; questions and answers travel between the wall and the phones through free public MQTT relays, encrypted with a key derived from that code. The source and tests live with the wall deck.
